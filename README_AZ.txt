MECHANIC MOBILE v1.1.0

Android üçün offline Avadanlıq / Təmir / Materiallar tətbiqi.

Funksiyalar:
- Avadanlıq inventarizasiyası
- Təmir qeydiyyatı və tarixçəsi
- Materiallar və qalıq
- Foto və fayl əlavə etmə
- Pictures/Mechanic və Documents/Mechanic qovluqları
- Offline SQLite
- Windows ilə Wi-Fi iki tərəfli sinxronizasiya
- Toqquşmaların idarə edilməsi

Qeyd: APK build üçün Android SDK/NDK + Buildozer mühiti tələb olunur.
Windows proqramının özü bu paketə daxil deyil.
